- feishu-import.service.ts: uploadAndPreview(解析+逐行校验)/ confirmImport(逐行事务)
  / 历史 / 模板 / 列映射 CRUD
- feishu-import.controller.ts: /imports/* 完整 API
- feishu-import.module.ts

- 路由 /data-import + 菜单(质量合规组)
