## 二、金现代 LIMS 典型客户案例（验证产品成熟度）

| 客户 | 行业 | 核心痛点 | 解决方案 |
|---|---|---|---|
| **华电集团** | 能源（70+ 实验室）| CNAS 体系人工维护工作量大、审批慢 | 与 CNAS 评审专家共建符合 2018 新版体系 |
| **贵州茅台** | 白酒 | 17025 全要素管控、从记录到报告全程电子化 | 17025 体系内置 + 大实验室理念（6 个实验室一体化）|
| **宁德时代** | 新能源电池 | 研发过程不清晰、数据难溯源、记录不便捷 | ELN 模板自定义 + 自动打标签结构化 |
| **浪潮信息** | 服务器 | CNAS 规范、远程监控设备、设备预约 | 设备状态监测反控 + 设备预约排配 |
| **日照钢铁** | 钢铁 | 老旧设备无法对接（"数据不落地"）、业务不规范、数据篡改风险 | **AI 取数（OCR 拍照识别）+ 人脸核身 + 盲样管理** |
| **广电计量** | 计量检测 | 模板泄露、1800+ 计量能力 50000+ 模板修改难 | 零代码自定义 + 模板防泄露 + 报告样式自适应 |
| **宁波科元精化** | 化工 | 排班/微信群任务分配、跨部门协同差、数据重复填写 | 智能排班 + 委托单样品全流程追踪 + 报表自动生成 |

### 💡 关键洞察

**1）行业适配能力极强**：覆盖能源/食品/化工/钢铁/电子/计量 — 都能跑通
**2）老旧设备兼容方案**：**AI 取数（OCR）** 解决无串口设备的数据采集（敦煌金可以直接借鉴）
**3）防作弊机制**：**人脸核身 + 盲样管理**（样品信息隔离、角色生成不同编码）— 适合检测公正性
**4）信创支持**：全面支持国产化软硬件（中科曙光服务器、国产数据库/操作系统）— 国企采购关键

## 五、敦煌金检测中心 LIMS 改进方案（分 4 阶段）

### 🚀 阶段 1：核心能力补齐（0-3 月，P0 优先级）

#### 1.1 ELN 电子实验记录本（最大缺口）

**目标**：将"项目管理"从纯登记表升级为 ELN

**实施要点**：
- [ ] **实验记录模板系统**：基于 `page-projects` 扩展，支持自定义模板字段
- [ ] **内置公式 + 自动计算**：检测限值、回收率、相对偏差
- [ ] **结果自动判定**：检测指标上下限 → 超限红字提醒
- [ ] **数据校验**：漏填提醒 + 异常值提醒
- [ ] **修改留痕**：每次修改产生审计记录（已用 SHA256 链）

**UI 改造参考（金现代风格）**：

```
┌─────────────────────────────────────────────────────────┐
│  实验记录  [样品: SP-2026-001▼]  [方法: ICP-MS▼]        │
├─────────────────────────────────────────────────────────┤
│  ┌──────────────────────────┐  ┌────────────────────┐  │
│  │ 实验基础数据              │  │ 检测数据录入        │  │
│  │ 样品名：Au 矿石          │  │ 元素  标准值  测得值│  │
│  │ 检测员：张三  [自动]     │  │ Au    10.5    10.3 │  │
│  │ 设备：ICP-MS [自动]      │  │ Ag     2.0     1.95│  │

│  └──────────────────────────┘  └────────────────────┘  │
│  [自动判定] ✓ 全部合格  [保存]  [提交复核]              │
└─────────────────────────────────────────────────────────┘
```

#### 1.2 设备自动取数（OCR + 串口）

**借鉴金现代日照钢铁案例** — 老旧设备无串口时的解决方案：

- [ ] **AI-OCR 拍照取数模块**（最高 ROI）
  - 检测员拍照 → OCR 识别读数 → 自动填入 ELN
  - 支持设备：原子吸收、XRF、滴定仪等无串口设备
  - 培训成本：< 1 天
- [ ] **串口取数 SDK**（中期）
  - 支持 RS232/RS485/Modbus 协议
  - 与 ELN 集成：设备读数 → 自动写入检测结果
- [ ] **协议取数 SDK**（长期）
  - 支持 OPC UA、TCP/IP 自定义协议

**ROI 分析**：
- 减少人工抄录时间：**60-80%**（每个样品节省 5-10 分钟）
- 杜绝人工录入错误：**> 95%**（金现代案例数据）
- 单设备投入：< ¥2000（OCR 方案 vs ¥50,000 换新设备）

#### 1.3 报告自动生成

- [ ] **报告模板系统**：用户自定义（数据绑定 + 公式）
- [ ] **电子签名 + PDF 导出 + 水印 + 骑缝章**
- [ ] **报告审批流**：编制 → 审核 → 签发 → 归档

## 七、关键技术决策建议

### 7.1 是否引入金现代 LIMS？

| 维度 | 自研 | 采购金现代 |
|---|---|---|
| **初期成本** | 低（已投入）| 高（百万级）|
| **定制能力** | 极强 | 中等（依赖厂商）|
| **数据自主** | 完全自主 | 厂商托管 |
| **行业适配** | 金矿专属 | 通用（需定制）|
| **长期成本** | 低（仅维护）| 中（年费 + 升级）|
| **CNAS 评审** | 需自建 | 直接通过 |

**建议**：
- **金矿检测领域知识** 是敦煌金的护城河（"金"检测方法）— 自研更合适
- **借鉴金现代的架构和功能清单** — 取其精华
- **采购部分标准模块**（如 OCR 设备对接、报告引擎）— 加速建设

### 7.2 架构升级路径

```
当前（单体应用）：

  + ELN 模块
  + OCR 集成 SDK
  + 报告引擎（PDFKit + Puppeteer）

阶段 2：
  + 任务引擎（Bull/BullMQ）
  + 通知中心（WebSocket）

阶段 3：
  + 微服务化（可选）
  + 消息队列（RabbitMQ/Kafka）
  + 缓存层（Redis）

阶段 4：
  + AI 模型私有化部署
  + 数据中台
  + 低代码平台
```
