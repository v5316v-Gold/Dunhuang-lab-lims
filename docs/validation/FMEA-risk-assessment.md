# FMEA — Risk Assessment (失效模式与影响分析)

> **项目**: 敦煌金质检 LIMS
> **版本**: v1.0
> **日期**: 2026-08-13
> **方法**: ICH Q9 + GAMP 5 Risk Management
> **范围**: Phase 0.5 完成的 LIMS 核心模块
> **评分标准**: 严重性(S) × 可能性(P) × 可检测性(D) = RPN (Risk Priority Number)

---

## 1. 评分标准

### 1.1 严重性 Severity (S)

| 分数 | 影响 |
|---|---|
| 10 | 患者/客户安全,法规合规严重破坏,数据丢失/不可恢复 |
| 8-9 | 报告错误导致客户决策错误,审计链完全断链 |
| 6-7 | 单条记录错误但可检测,审计链部分断链 |
| 4-5 | 系统功能受限但有 workaround |
| 2-3 | 轻微不便,无数据影响 |
| 1 | 无影响 |

### 1.2 可能性 Probability (P)

| 分数 | 频率 |
|---|---|
| 10 | 每次操作都发生(>50%) |
| 8-9 | 经常(10-50%) |
| 6-7 | 偶尔(1-10%) |
| 4-5 | 罕见(0.1-1%) |
| 2-3 | 极罕见(0.01-0.1%) |
| 1 | 几乎不可能(<0.01%) |

### 1.3 可检测性 Detectability (D)

| 分数 | 可检测性 |
|---|---|
| 10 | 完全无法检测 |
| 8-9 | 检测概率极低(<10%) |
| 6-7 | 有方法但实施困难(10-50%) |
| 4-5 | 中等(50-80%) |
| 2-3 | 高(80-95%) |
| 1 | 几乎确定检测(>95%,自动监控) |

**RPN = S × P × D**(最大 1000)
- RPN ≥ 100:**高风险**,必须立即降低
- RPN 50-99:**中风险**,需采取控制措施
- RPN < 50:**低风险**,可接受

## 5. 残余风险接受

Phase 0.5 完成后,以下风险**可接受**:
- 所有 RPN < 50 的风险(33 个)
- R-05 (audit ID 跳号, RPN 48):不连续不影响业务
- R-11 (样品 ID 重复, RPN 16):有 unique 约束保护
- R-20 (JWT 密钥泄露, RPN 20):开发阶段可接受,生产前必须改 K8s Secret
- R-32 (数据库宕机, RPN 27):Docker 重启可恢复,Phase 5 双机热备

Phase 0.5 完成后,**必须**在 Phase 1-5 解决:
- R-12 (称样量单位, RPN 180,极高)
- R-30 (性能, RPN 168,极高)
- R-31 (audit 表过大, RPN 144,高)
- R-10 (测试结果错误, RPN 120,高)
- R-50 (仪器数据, RPN 120,高)
- R-33 (备份恢复, RPN 100,高)
- R-21 (越权, RPN 96,高)
- R-22 (弱密码, RPN 80,高)
- R-41 (备份损坏, RPN 80,高)
- R-03 (TRUNCATE, RPN 70,中)
