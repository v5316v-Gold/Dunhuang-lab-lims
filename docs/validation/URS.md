# URS — User Requirements Specification (用户需求规格)

> **项目**: 敦煌金质检 LIMS
> **版本**: v2.0(定稿) | 2026-08-15
> **编制**: LIMS-Architect-01
> **状态**: 定稿(Phase 1C 完成,CNAS 现场评审前)
> **对应**: VMP §1(范围)、FMEA 风险输入

---

## 1. 文档目的

明确 CNAS-CL01:2018(等同 ISO/IEC 17025:2017)认可的贵金属(黄金)检测实验室信息管理系统(LIMS)的**用户级需求**,作为后续 FS/DS/IQ/OQ/PQ 验证的源头文档。

## 2. 干系人

| 角色 | 关注点 |
|---|---|
| 实验室主任 | 全流程合规 + 战略价值 |
| 质量经理 | 审核签发 + 体系符合 |
| 高级检测员 | 火试金流程 + 工艺完整性 |
| 检测员 | ICP 流程 + 数据录入 |
| 设备管理员 | 设备三查合规(校准/维护/期间核查) |
| 试剂管理员 | 库存 + 效期 + 低库存预警 |
| 客户(上海黄金交易所等) | 报告法律效力 + 准确性 |
| CNAS 评审员 | 审计链 + 防篡改 + 数据完整性 |

## 3. 业务需求(URS-1xx)

### 3.1 样品管理(URS-1xx)
- **URS-101**: 系统应能生成符合 YYMMDD-NNNN 格式的唯一样品编号,日序列在并发 100+ 请求下无重复
- **URS-102**: 系统应强制 9 态样品生命周期(RECEIVED → ARCHIVED),非法流转应被守卫拒绝(400)
- **URS-103**: 样品留样应可标记 ≥6 个月到期(CNAS §8.4)

### 3.2 检测执行(URS-2xx)
- **URS-201**: 火试金工艺应强制 6 步顺序(称样→熔融→灰吹→分金→退火→称重),跳步应被业务服务拒绝
- **URS-202**: 火试金纯度计算应使用 Decimal 精度(避免浮点误差),QC 回收率 99.5-100.5% 范围应被校验
- **URS-203**: ICP 多元素结果应支持批量录入,主元素(Au)应自动更新 sample.purityPct

### 3.3 质量控制(URS-3xx)
- **URS-301**: Westgard 规则(1₃s/2₂s/R₄s/4₁s/10x)应能基于 Z-score 历史自动判定
- **URS-302**: QC 失败应自动联动批次 REJECTED 状态
- **URS-303**: QC 测量数据应可回溯至具体检测任务与样品

### 3.4 报告交付(URS-4xx)
- **URS-401**: 报告应强制三级审核(DRAFT → INTERNAL_REVIEW → FINAL_REVIEW → APPROVED → ISSUED),驳回应能回到上一态
- **URS-402**: 报告签发时应自动生成 PDF 并绑定 SHA256 哈希
- **URS-403**: 电子签名应符合 21 CFR Part 11(双因素 + 时间戳 + 不可否认),Mock TSA 在 Phase 5,真实 RFC3161 接入在 Phase 6+
- **URS-404**: 报告内容应包含检测数据快照(不可篡改)

### 3.5 设备管理(URS-5xx)
- **URS-501**: 设备校准过期应被检测模块拦截(CNAS §6.4)
- **URS-502**: 设备三查(校准/维护/期间核查)综合健康状态应可一目了然

### 3.6 试剂管理(URS-6xx)
- **URS-601**: 试剂库存应支持低库存预警(remaining ≤ safetyStock)
- **URS-602**: 效期 30 天内的试剂应自动预警
- **URS-603**: 试剂出库应原子扣减(Decimal 精度)

### 3.7 人员管理(URS-7xx)
- **URS-701**: 检测人员应需能力授权才能执行对应方法,授权过期自动失效
- **URS-702**: 培训记录与能力矩阵应可追溯

### 3.8 数据完整性(URS-8xx)
- **URS-801**: 任何数据变更应触发 SHA256 审计链记录(append-only)
- **URS-802**: 审计链断链应能被 verify 端点检测
- **URS-803**: 审计链 UPDATE/DELETE/TRUNCATE 应被 DB 触发器拒绝
- **URS-804**: 数据保留 ≥5 年(CNAS §8.4)

### 3.9 系统集成(URS-9xx)
- **URS-901**: 系统应能通过 RESTful API 集成 ERP/MES
- **URS-902**: 配置文件变更不应需重启(运行时热加载 env 校验)

## 4. 非功能需求(NFR)

| 编号 | 需求 |
|---|---|
| NFR-01 | 性能: 1000 样品/天,API P95 < 500ms |
| NFR-02 | 可用性: SLA 99.9%(年度停机 < 8.76h) |
| NFR-03 | 安全: 等保 2.0 二级(Phase 4 已差距分析) |
| NFR-04 | 可维护: 单元测试覆盖率 ≥70%(Phase 5 待建立),集成测试 76 项 PASS |
| NFR-05 | 兼容: Chromium 浏览器 + Windows 11 + Node 22 |

## 5. 合规要求

| 标准 | 对应 |
|---|---|
| CNAS-CL01:2018 §6/§7/§8 | 全部 URS 映射 |
| ISO/IEC 17025:2017 | 等同采用 |
| 21 CFR Part 11 §11.50/§11.70 | URS-403 |
| ALCOA+ 9 原则 | URS-801 至 804 |
| 等保 2.0 二级 | NFR-03 |

- 所有 URS-1xx 至 URS-9xx 在 FS 中逐条对应
- OQ 测试用例 100% 覆盖 URS 条目
- PQ 在 2026-10 末完成 1000 样品/天压测
