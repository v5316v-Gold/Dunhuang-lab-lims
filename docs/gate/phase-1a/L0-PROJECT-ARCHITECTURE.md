## 2. 项目章程(Charter)

### 2.1 一句话定位
> **面向贵金属检测的 CNAS-CL01:2018 + CMA 双合规实验室信息管理系统(LIMS),覆盖「样品接收 → 检测 → 报告 → 贵金属条码」全流程。**

### 2.2 项目愿景
敦煌金质检实验室于 **2026-11-03** 通过 CNAS 现场评审 + CMA 计量认证,系统作为唯一可信数字化底座,**完整替代手工记录 + Excel**,实现「**每一份检测报告都可逐条溯源到人员 / 设备 / 标准物质 / 校准证书 / 不确定度分量**」。

### 2.3 项目边界(In / Out of Scope)

**In-Scope(必须交付)**:
| 类别 | 范围 |
|---|---|
| 业务 | 黄金 / 白银 / 铂 / 钯 / 铑 / 铱 / 锇 / 钌 检测 + 火试金法 / ICP-OES / 容量法 / 滴定法 |
| 合规 | CNAS-CL01:2018 + ISO/IEC 17025:2017 + CMA 计量认证 |
| 数据 | 样品 / 检测 / 报告 / 标准物质 / 校准 / 期间核查 / 不确定度 / 危废 / 气体 / 容器 / 贵金属条码 |
| 用户 | 实验室内部人员(管理员 / 质量经理 / 高级分析员 / 分析员 / 设备员)|
| 集成 | MinIO(证书 PDF) + MinIO / 本地存储(报告 PDF) |
| 部署 | 自托管 Docker Compose(本地 + 异地灾备备份)|

**Out-of-Scope(明确不做)**:
- ❌ 多租户 SaaS(只服务敦煌金一家)
- ❌ 客户自助查询门户(报告只能从实验室发,不走外网)
- ❌ 移动 App(PWA 后续可选,本阶段不做)
- ❌ 区块链存证 / 国密算法(评审要求后再加)
- ❌ 跨境数据传输 / GDPR(纯国内业务)

### 2.4 五零承诺("5 个零")

| # | 承诺 | 含义 |
|---|---|---|
| 1 | **零手工** | 所有检测记录、报告、危废、气体、容器扫码入库,无 Excel / 纸质台账 |
| 2 | **零篡改** | ALCOA+ 数据完整性原则 + 审计链 + DB trigger + 不可变字段 |
| 3 | **零缺失** | 关键字段必填校验 + 状态机防漏 + 期间核查 / 校准 / 培训到期前告警 |
| 4 | **零争议** | 测量不确定度可逐分量溯源(§7.8)+ 标准物质证书可哈希验证 |
| 5 | **零外泄** | 全自托管 + 内网部署 + 数据库备份 3-2-1 + 等保 2.0 三级 |

## 4. 核心业务闭环(5 大闭环)

### 闭环 1: 样品检测闭环

```
客户送样 → 接样登记(SamplingRecord)
        → 样品接转(Sample状态:RECEIVED)
        → 批次编排(SampleBatch)
        → 检测任务(Test, 状态:PENDING)
        → 检测执行(operatorId + startedAt)
        → 检测完成(Test状态:COMPLETED + purityPct + uncertainty)
        → QC 测量(QcMeasurement + Westgard 规则)
        → 报告生成(Report, 三级审核)
        → 报告签发(ISSUED, PDF + sha256)
        → 贵金属条码(PreciousMetalBar BAR-AU-...)
        → 客户取回(留样登记)
```

### 闭环 2: 设备合规闭环

```
设备采购入库(Equipment)
    → 校准(Calibration, 证书 PDF + sha256)
    → 投入运行(Equipment.status = ACTIVE)
    → 期间核查(PeriodicCheck, z-score)
    → 校准到期前告警(realtime.push)
    → 重新校准(新 Calibration 记录)
    → 退役 / 报废(Equipment.status = RETIRED)
```

### 闭环 3: 危废合规闭环

```
检测产生危废(WasteRecord 登记, 来源 Test.id)
    → 暂存(状态:STORED)
    → 转移(状态:TRANSFERRED, 接收企业 + 资质证号 + 联单号)
    → 处置(状态:INCINERATED / RECYCLED_GOLD / DISPOSED, 处置方式 + 海绵金回收字段)
    → 留档(不可删)
```

### 闭环 4: 人员资质闭环

```
人员入职(Personnel 建档)
    → 培训(Training, 含课程 / 成绩 / 有效期)
    → 能力评估(Competency, 按方法:FIRE_ASSAY / ICP_OES / GRAVIMETRY ...)
    → 资质授权(UserRoleAssignment)
    → 持续培训(到期前告警)
    → 离职 / 调岗(角色自动失效)
```

### 闭环 5: 试剂 / 气体 / 容器闭环

```
采购申请 → 到货验收(ReagentLot / Gas / Container)
        → 入库(库存数量增加)
        → 领用(创建 Usage 记录 + 库存减少 + 检测/QC 关联)
        → 消耗 / 归还(库存 / 状态变更)
        → 过期告警 / 低库存告警 / 校准告警(realtime 推送)
        → 退役 / 报废(留档)
```
