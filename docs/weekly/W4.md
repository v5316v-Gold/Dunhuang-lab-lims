## 3. Demo 记录(评审可演示)

### Demo 1: 报告 PDF 深化
```
POST /api/v1/reports/:id/transition {event: "ISSUE"}
→ 自动生成 PDF(含纯度 + U(k=2)+ 签字链 + 水印 + SHA256)
GET /api/v1/reports/:id/pdf
→ 下载 PDF(inline 查看,X-PDF-SHA256 header)
```

### Demo 2: 校准证书查看
```
POST /api/v1/files/upload(multipart: file + category=CERTIFICATE + equipmentId)
→ { id, sha256 }
GET /api/v1/files/download/:id
→ inline 查看 PDF + X-File-SHA256(防伪)
GET /api/v1/files/verify/:sha256
→ { valid: true }
```

### Demo 3: 留样到期告警
```
POST /api/v1/samples/:id/archive {location, months}
→ status=ARCHIVED + retentionUntil
GET /api/v1/samples/retention/expiring?days=7
→ 到期列表
(后台每 6h 自动扫描 → SSE 推送 SAMPLE_RETENTION_EXPIRING)
```
