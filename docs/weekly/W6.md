## 2. 关键产出(评审可演示)

### Demo 1: 临时授权(代班)
```
POST /compliance/temp-auth
{ granteeId, method, effectiveFrom, effectiveTo, reason }
→ TA-YYYYMMDD-NNNN 状态=ACTIVE
POST /compliance/temp-auth/:id/revoke → REVOKED + revokedById
```

### Demo 2: 监督记录
```
POST /compliance/supervision
{ supervisorId, superviseeId, supDate, content, result }
→ SUP-YYYYMMDD-NNNN
result=CONCERN/FAIL 时无 correctiveAction → 400(系统级强制)
```

### Demo 3: 盲样考核
```
POST /compliance/blind-sample → BL-YYYYMMDD-NNNN + 真值
POST /compliance/blind-sample/:id/assess { measuredValue }
→ 自动算偏差 |measured-truth|/truth × 100%
偏差 ≤5% → passed=true(绿)
偏差 >5% → passed=false(红)
```
