# W9-5 模拟 CNAS 评审不符合项整改模板

> **用途**: 模拟评审发现的不符合项,正式评审前全部整改关闭
> **原则**: 模拟评审的问题 = 正式评审会问的问题,必须 100% 关闭

---

## 1. 整改单(逐项)

### 模板

| 字段 | 内容 |
|---|---|
| NCR 编号 | MOCK-NCR-XXX |
| 条款 | CNAS-CL01:2018 §X.X |
| 不符合描述 | 模拟评审发现的问题 |
| 严重度 | 轻微 / 重大 |
| 根因 | 为什么发生 |
| 整改措施 | 具体怎么改 |
| 责任人 | 谁负责 |
| 完成日期 | 何时完成 |
| 验证方式 | 测试用例 / 现场演示 |
| 验证人 | QA Manager |
| 状态 | 待整改/整改中/已整改/已关闭 |

---

## 2. 模拟评审常见不符合项(预判 + 预防)

| 场景 | 预防措施 | 系统支持 |
|---|---|---|
| 合同评审缺失 | Phase 2 补 Contract 表 | 待补 |
| 投诉处理缺失 | Phase 2 补 Complaint 表 | 待补 |
| 报告 PDF 打不开 | 提前测下载 + 兼容浏览器 | ✅ W+4 已修 |
| 审计日志查询慢 | 加索引 | 待评估 |
| 临时授权无记录 | 已有 TemporaryAuthorization | ✅ W+2 已做 |
| 留样无到期提醒 | 已有 retentionUntil + SSE | ✅ W+4 已做 |
| 校准证书无法查看 | 已有文件下载 | ✅ W+4 已做 |

---

## 3. 整改完成标准

- [ ] 所有不符合项有根因
- [ ] 每项有整改 + 验证
- [ ] 100% 关闭
- [ ] 双人签字(整改人 + QA)
- [ ] 记录归档

---

## 4. 整改后复审

- 复审时间: 整改完成后 1 周内
- 复审方式: 抽查已关闭 NCR + 复测
- 复审结论: 通过 → 进入 W+10 最后准备
