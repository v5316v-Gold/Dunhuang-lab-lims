## 2. 内审重点抽查(现场演示)

### 2.1 数据完整性抽查(ALCOA+)

- [ ] 抽查 5 条样品,追溯到操作者/时间/IP
- [ ] 抽查 3 份报告,追溯签字链
- [ ] 尝试 UPDATE audit_logs → 确认被 DB trigger 拒绝

### 2.2 状态机抽查

- [ ] 报告非法跳转(如 DRAFT→ISSUED)→ 确认 400
- [ ] 危废非法跳转(STORED→INCINERATED)→ 确认 400
- [ ] 样品非法跳转 → 确认 400

### 2.3 不确定度抽查

- [ ] 抽查 1 份 UncertaintyReport,查看 5 类分量 + 公式
- [ ] 确认 Test.uncertainty 已同步

### 2.4 标准物质抽查

- [ ] 抽查过期 RM → 确认系统阻断
- [ ] 抽查 RM 使用台账 → 追溯 ElementResult

### 2.5 报告 PDF 抽查

- [ ] 签发 1 份报告 → 下载 PDF → 验证 sha256 一致
- [ ] 验证水印 + 签字链 + 不确定度段

### 2.6 越权抽查

- [ ] 用 ANALYST 账号改他人样品 → 确认 403
