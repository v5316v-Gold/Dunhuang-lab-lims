## 🔍 检查中发现的 8 个问题

### 🔴 P0 问题（必须立即修复）

#### P0-1: `routes/sample.js` 未在 `server.js` 中挂载
- **现象**：访问 `/api/samples`、`/api/appointments`、`/api/sample-processing` 报 404
- **根因**：server.js 早期代码漏掉 `app.use('/api', require('./routes/sample'))`
- **影响**：8 个样品相关 API 全部失效（样品预约/处理/二维码/收样/留样等）
- **状态**：✅ **已修复**

#### P0-2: `routes/training` 模块没有 `GET /training` 列表路由
- **现象**：访问 `/api/training` 报 404（菜单"培训记录"打不开）
- **根因**：fumehood.js 只定义了 `/training-annual` 和 `/training-records`，没有 `/training` 列表
- **影响**：培训记录页面无法显示
- **状态**：✅ **已修复**（添加 `training.get('/training', ...)`）

#### P0-3: `/api/experimental-data` 路由不存在
- **现象**：实验数据报告页面 404
- **根因**：server.js 路由是 `/api/experimental-data-reports`（带 -reports 后缀），菜单调用无后缀
- **影响**：实验数据报告页面打不开
- **状态**：✅ **已修复**（添加别名路由 `/api/experimental-data`）

---

### 🟡 P1 问题（建议尽快修复）

#### P1-1: 13 个 Node 残留进程（PID 列表）
- **现象**：`tasklist | findstr node.exe` 显示 13 个 node 进程
- **根因**：之前的多次调试和重启未清理
- **影响**：占用内存（~520 MB），可能导致端口冲突
- **状态**：✅ **已修复**（写了 `start-clean.bat` / `start-clean.sh` 自动清理）

#### P1-2: 服务器启动时 P0-MIGRATION 有 4 个错误
```
[P0-MIGRATION] Errors: [
  {"idx":5,"msg":"FOREIGN KEY constraint failed"},
  {"idx":6,"msg":"there is already another table or index with this name: projects"},
  {"idx":12,"msg":"FOREIGN KEY constraint failed"},
  {"idx":13,"msg":"there is already another table or index with this name: samples"}
]
```
- **根因**：迁移脚本尝试 `CREATE TABLE IF NOT EXISTS`，但旧表已存在导致冲突
- **影响**：4 个 P0 迁移失败（重复建表/外键）
- **状态**：⚠️ **不影响功能**（已存在的表结构正确），但日志噪音

#### P1-3: 实验数据报告表 `experimental_data_reports` 不存在
- **现象**：日志 `[queryAll err] no such table: experimental_data_reports`
- **根因**：该表的 CREATE TABLE 在 schema.js 中遗漏了
- **影响**：实验数据报告功能部分失效
- **状态**：⚠️ **需要补全 schema**
