# W8-1 全员培训教材大纲(LIMS 试运行前培训)

> **培训对象**: 敦煌金质检实验室全员(11 人,分 4 组)
> **培训时长**: 2 小时 × 4 组(共 8 小时)
> **培训人**: 系统管理员 + QA Manager
> **考核方式**: 上岗实操考核 + 笔试
> **目的**: CNAS 现场评审前,全员能熟练操作系统,避免评审现场操作失误

---

## 1. 培训分组与目标

| 组 | 角色 | 人数 | 核心培训内容 |
|---|---|---|---|
| **A 组** | 实验室主任 / QA Manager / LAB_DIRECTOR | 3 | 全模块 + 审核 + 管评 + 内审 |
| **B 组** | 高级分析员(火试金 / ICP) | 2 | 接样→批次→检测→QC→报告 |
| **C 组** | 分析员 | 4 | 接样→检测录入→报告起草 |
| **D 组** | 设备员 / 试剂危废管理员 | 2 | 设备校准 / 期间核查 / 试剂 / 危废 / 气体 / 容器 |

## 3. 培训考核标准

### 3.1 实操考核(每组 1 项,60 min)

| 组 | 考核任务 | 通过标准 |
|---|---|---|
| A | 走完整报告签发流程 + 下载 PDF 验 sha | 5 步全通,PDF sha 匹配 |
| B | 火试金批次:创建→工艺参数→称重→纯度计算 | 状态机不卡壳 |
| C | 接样→检测→报告起草 | 3 步全通 |
| D | 危废登记→转移(资质证号)→处置 | 3 步全通 |

### 3.2 笔试(20 题,30 min)

- 每题 5 分,80 分及格
- 覆盖:ALCOA+ / 状态机 / 审计链 / RBAC / 合规模块

### 3.3 上岗授权

- 实操 + 笔试均通过 → 系统内分配对应角色(UserRoleAssignment)
- 未通过 → 补训 1 次,仍不通过 → 暂缓授权
