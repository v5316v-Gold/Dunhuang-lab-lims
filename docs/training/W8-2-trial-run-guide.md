## 2. 试运行录入流程(按日)

### Day 1(周一): 基础数据

```
- 设备校准: 录入 3 台设备的校准证书 + 期间核查
- 试剂库存: 录入 5 种试剂 + 批次 + 效期
- 标准物质: 录入 3 个 RM + 证书 SHA256 + 使用台账
- 容器: 录入 10 个容器(坩埚/容量瓶/滴定管)
```

### Day 2(周二): 样品 + 检测

```
- 接样: 30 条样品(客户/类型/重量)
- 批次: 创建 3 个火试金批次
- 检测: 火试金工艺参数 + 称重 + 纯度
- ICP: 校准曲线 R² + 多元素结果
```

### Day 3(周三): QC + 不确定度

```
- QC 测量: 15 条(空白/平行/标准/加标)
- Westgard 触发: 故意造 1 条 z>3 触发 OOS
- 不确定度: 3 份 UncertaintyReport(5 类分量)
```

### Day 4(周四): 报告 + 条码 + 合规

```
- 报告: 10 份(5 份走完 5 级签发)
- 贵金属条码: 5 条 BAR-AU
- 取样记录: 8 条(现场/客户送样)
- 盲样/PT: 5 条(录入考核结果)
```

### Day 5(周五): 支持资源 + 审批

```
- 危废: 8 条(转移→处置)
- 气体: 5 种 + 10 次领用
- 临时授权: 2 条
- 内审/管评/监督: 各 3 条
```

---

## 3. 数据录入注意事项

### 3.1 状态机(不可跳步)

- 报告: DRAFT→INTERNAL_REVIEW→FINAL_REVIEW→APPROVED→ISSUED(不可跳过)
- 样品: RECEIVED→BATCHED→IN_TEST→TESTED→ARCHIVED→DISPOSED
- 危废: STORED→TRANSFERRED→INCINERATED/RECYCLED_GOLD/DISPOSED

### 3.2 必填字段(CNAS 合规)

- 火试金工艺参数: 炉温 + 灰吹时长 + 分金酸
- ICP: 校准曲线 R²(≥0.999)
- 危废转移: 接收企业资质证号
- 不确定度: 5 类分量 + 公式快照
- 标准物质: 证书 SHA256

### 3.3 审计链验证

每次操作后,检查审计日志:
```
GET /audit-logs?user=xxx&date=xxx
```
确认记录了:who / when / what / 旧值 / 新值 / IP
