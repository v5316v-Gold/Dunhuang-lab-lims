# W8-3 试运行 Bug 收集模板

> **用途**: 试运行期间(1 周)统一收集系统问题
> **流转**: 记录 → 分级 → 修复 → 验证 → 关闭

---

## 1. Bug 记录表(每日填写)

| 字段 | 说明 | 示例 |
|---|---|---|
| Bug ID | 自动编号 BUG-001... | BUG-001 |
| 发现人 | 姓名 | 张三 |
| 发现时间 | 日期+时间 | 2026-08-16 10:30 |
| 模块 | 哪个功能 | 报告签发 |
| 严重度 | P0/P1/P2 | P0 |
| 现象描述 | 详细步骤 | 点"签发"报 500 |
| 预期结果 | 应该怎样 | 生成 PDF |
| 实际结果 | 实际怎样 | 500 错误 |
| 截图/日志 | 附件 | screenshot.png |
| 状态 | 新/修复中/已修复/已验证/关闭 | 新 |

---

## 2. 严重度分级

| 级别 | 定义 | 响应时间 | 处理 |
|---|---|---|---|
| **P0** | 数据丢失 / 系统崩溃 / 无法完成核心业务 | 立即(2h 内) | 停止使用该功能 |
| **P1** | 功能错误 / 状态机卡住 / 字段缺失 | 当天 | 修复 + 回归 |
| **P2** | 体验不佳 / 建议优化 | 迭代 | 排期 |

---

## 3. Bug 流转流程

```
发现 → 记录(模板) → 分级
  ↓
P0: 立即报告系统管理员 + 停止使用该功能
P1: 当天提交 → 系统管理员修复 → 当天验证
P2: 记录 → 排期迭代
  ↓
修复 → 回归测试 → 关闭(记录修复 commit)
```

---

## 4. 试运行期间常见问题(预判)

| 场景 | 可能原因 | 处理 |
|---|---|---|
| 报告签发 500 | PDF 生成问题 | 检查 pdfSha256 |
| 状态机卡住 | 非法转换 | 检查当前状态 |
| 危废转移 400 | 缺资质证号 | 补字段 |
| 不确定度算不出 | 分量未填 | 检查 5 类分量 |
| 越权 403 | Ownership 守卫 | 检查数据所有权 |
| QC 失控 | Westgard 规则 | 检查 z-score |
