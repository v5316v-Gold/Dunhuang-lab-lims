## 六、评审必带的"杀手锏"

1. **审计链离线校验脚本**:`scripts/audit-verify.ts --full` → 100% 通过
2. **电子签名验证**:`openssl smime -verify ...` → 显示完整证书链
3. **GUM 不确定度计算器**:`apps/backend/src/common/qc/westgard.ts` → 展开 5 类分量
4. **Westgard 自动判断**:`apps/backend/src/common/qc/westgard.ts` → 6 规则
5. **状态机守卫**:尝试非法转移 → 422 错误 + 审计
6. **MFA challenge**:现场要求实验室主任做一次签发,演示 MFA 弹窗
7. **告警系统**:`http://192.168.x.52:9090/alerts` → 展示告警规则 + 当前状态

## 七、评审员可能挑剔的点 + 准备

| 挑剔 | 准备 |
|---|---|
| "软删除的样品还在出报告?" | 演示 `findUnique` 默认过滤 + `includeDeleted=true&role=ADMIN` 才返回 |
| "审计链离线校验的证据?" | 跑 `scripts/audit-verify.ts --full` + 给出整链 SHA256 输出 |
| "你的 Mock CA 不算电子签名" | 用 RFC 3161 TSA 时间戳 + SHA-256 + 完整证书链 |
| "MFA 没强制,普通员工没启用" | 演示 `mfaRequired=true` 字段 + ADMIN/QA 必须启用 |
| "数据备份最近一次?" | 展示 7 天每日备份 + 月度还原演练记录 |
| "管理评审怎么做的?" | 系统自动汇总 12 项输入 + 上次管评决议跟进 |
