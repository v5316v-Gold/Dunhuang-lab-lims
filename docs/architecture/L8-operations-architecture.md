## 1. 节点名称

**L8-运维架构**(Operations Architecture / 持续运营架构)

## 2. 建设目标

1. 定义**监控与告警体系**(指标/日志/链路)
2. 定义**事件管理**(P0-P3 分级与响应)
3. 定义**变更管理 SOP** 与发布流程
4. 定义**备份恢复与 DR 演练**
5. 固化**周期性复核**(每日→年度)
6. 定义 **SLA**(99.9%+ 可用性)
7. 为 CNAS 现场评审后的持续合规提供运维支撑

## 3. 业务范围

- **In-scope**:
  - 生产 7×24 运营
  - 监控(应用/DB/缓存/基础设施)
  - 事件/工单/变更管理
  - 备份/恢复/灾备演练
  - 周期复核(引用 periodic-review-plan)
- **Out-of-scope**:
  - 验证体系 → 归 L7
  - 基础设施设计 → 归 L6

## 4. 背景

`docs/validation/periodic-review-plan.md` 已定义完整复核周期(每日自动检查/每周简报/每月性能/每季度风险/半年变更/年度完整)。本层将运维**固化为架构规范**,重点补监控体系、事件分级、SLA 与变更流程。

## 7. 前置后置条件

- **前置**: L7 GATE PASS(验证放行)
- **后置**: 上线放行 + 首次监控演练通过 + 复核排期确认

## 8. 业务流程

运维主流程(文字描述):

```
监控采集 → 阈值告警 → 事件分级(P0-P3)→ 响应处置
  → 修复验证 → 复盘(CAPA)→ 周期性复核 → 持续改进
```

变更流程:变更申请 → 影响评估 → 审批 → 实施 → 验证 → 文档更新 → 复核。

## 9. 状态机

### 9.1 事件生命周期

| 状态 | 含义 | 进入事件 | 离开事件(目标) | 时限 |
|---|---|---|---|---|
| OPEN | 已登记 | 告警/报告 | 调查 → INVESTIGATING | P0:15min |
| INVESTIGATING | 调查中 | 响应 | 修复 → FIXING | P0:1h |
| FIXING | 修复中 | 方案确认 | 验证 → VERIFIED | P1:4h |
| VERIFIED | 已验证 | 修复完成 | 关闭 → CLOSED | 24h |
| CLOSED | 已关闭 | 复盘完成 | — | 2 周内 |

### 9.2 变更状态

REQUESTED → ASSESSED → APPROVED → IMPLEMENTED → VERIFIED → CLOSED / ROLLED_BACK

## 10. 数据模型

运维数据:

| 实体 | 说明 |
|---|---|
| 事件(Incident) | 级别/时间线/根因/修复 |
| 变更(Change) | CR 编号/影响/回滚 |
| 工单(Ticket) | 用户请求 |
| 复核报告 | 日/周/月/季/年度 |
| SLA 指标 | 可用性/响应时间 |

## 11. 字段(事件关键字段)

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 事件 ID | string | 是 | INC-YYYY-MM-DD-序号 |
| 级别 | enum | 是 | P0/P1/P2/P3 |
| 开始/结束时间 | datetime | 是 | 时间线 |
| 根因 | text | 否 | RCA |
| 修复 | text | 否 | 短期/长期 |
| CAPA | text | 否 | 预防措施 |

## 12. 业务规则

| 编号 | 规则 | 可测试性 |
|---|---|---|
| BR-O-01 | P0/P1 事件 15 分钟响应 | SLA 监控 |
| BR-O-02 | 变更必须评估影响 + 回滚预案 | 变更记录 |
| BR-O-03 | 周期复核按计划执行(日/周/月/季/年) | 复核记录 |
| BR-O-04 | 备份每日自动 + 每周全量 | 备份日志 |
| BR-O-05 | 季度 DR 演练 | 演练报告 |
| BR-O-06 | 事件复盘 CAPA 闭环 | CAPA 跟踪 |
| BR-O-07 | 生产变更窗口外禁止重大变更 | 变更审批 |
| BR-O-08 | 监控告警阈值变更需评审 | 告警配置审计 |

## 13. 异常处理

| 异常场景 | 检测方式 | 响应策略 |
|---|---|---|
| 告警风暴 | 告警聚合 | 抑制/降噪 |
| 备份失败 | 备份任务 | 重试 + 告警 |
| 证书过期 | 监控 | 自动续期 |
| 容量告急 | 磁盘/内存监控 | 扩容 |
| 数据异常 | 校验任务 | 冻结 + 调查 |
| 审计链断链 | verify 端点 | P1 响应 |
