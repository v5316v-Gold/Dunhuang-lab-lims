## 4. 关键业务特征(从数据观察)

### 4.1 工作流闭环

```
送样 → 检测领样 → 检测记录 → 试剂取用 → 废液废样登记
```

### 4.2 关键人员

- 6 名检测员(周燕平/王茜/李珍玉/刘秀民/郁万刚/薛鸿),分一/二组
- 设备管理员/气体采购员/复核人/双人复核等角色

### 4.3 关键标准

- **GB/T 9288-2019**(火试金法)
- **GB/T 38145-2019**(贵金属 ICP 检测)
- **QEGST/T01-2021**(企业内部标准)

### 4.4 关键合规点

| 字段 | 体现 |
|---|---|
| 复核人(入库/出库) | 双人复核 |
| 父记录(气体使用) | 溯源链 |
| 月份检索(库存) | 分区检索优化 |
| 物品图片(库存附件) | 实物照片存档 |
| 检测地点(编号房号) | 物理定位 |

### 4.5 检测方法学

- 火法(GB/T 9288-2019)+ ICP 两种主方法
- **执行标准字段是关键**(可对标准版本自动校验过期)
