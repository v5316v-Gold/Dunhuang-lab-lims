## 🔍 关键业务特征(从实际数据观察)

| 维度 | 观察 |
|---|---|
| 检测员 | 6 人(周燕平/王茜/李珍玉/刘秀民/郁万刚/薛鸿)分一/二组 |
| 主检测方法 | 火法(GB/T 9288-2019)+ ICP(GB/T 38145-2019) |
| 关键合规 | 双人复核(入库/出库)/ 父记录溯源链(气体使用)/ 库存附件图 |
| 业务闭环 | 送样 → 领样 → 检测 → 试剂取用 → 废液登记 |
