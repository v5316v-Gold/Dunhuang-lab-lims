## 填写指南(重点字段)

### 字段 2 建设目标
- 动词开头:定义/固化/设计/实现
- 每条可验证(对应验收标准)

### 字段 9 状态机
- 必须给出:状态全集、转换事件、守卫条件(谁在什么条件下允许转换)
- 这是 L4 应用实现与 L7 测试用例的直接依据

### 字段 12 业务规则
- 编号规范:`BR-<层标识>-<序号>`
  - L0 → BR-L0-01
  - L0.5 → BR-D-01(Domain)
  - L1 → BR-B-01(Business)
  - L2 → BR-C-01(Compliance)
  - L3 → BR-DATA-01
  - L4 → BR-APP-01
  - L5 → BR-T-01(Technology)
  - L6 → BR-INF-01(Infrastructure)
  - L7 → BR-V-01(Validation)
  - L8 → BR-O-01(Operations)
- 规则必须可测试(给出测试方法)

### 字段 16 合规要求
- 引用格式:`标准号 + 条款号 + 发布年`
- 例:`CNAS-CL01:2018 §7.5.1`
- 允许引用:`ISO/IEC 17025:2017`、`GB/T 27025-2019`、`21 CFR Part 11`、`GAMP 5`

### 字段 18 验收标准
- 必须是检查清单(□ 可勾选)
- 每一条对应一个可验证事实(文档/代码/测试/评审记录)
