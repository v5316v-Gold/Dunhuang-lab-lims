## 1. 节点名称

**L0.5-领域架构**(Domain Architecture / DDD 领域建模)

## 2. 建设目标

1. 识别领域边界与**限界上下文**(Bounded Context)清单
2. 定义**聚合根**(Aggregate Root)与实体归属
3. 定义**领域事件**(Domain Events)清单
4. 建立**领域术语表**(Ubiquitous Language,≥ 50 词)
5. 沉淀**领域规则**(业务不可绕过约束,≥ 10 条)
6. 为 L1 业务架构与 L3 数据架构提供建模基线

## 3. 业务范围

- **In-scope**:
  - 贵金属(黄金)检测全业务域:委托→接收→检测→质控→报告→归档
  - 核心方法域:火试金法(占比 ~70%)+ ICP-OES/ICP-MS(占比 ~25%)+ 辅助方法(~5%)
  - 支撑域:设备/试剂/人员/方法/EHS
- **Out-of-scope**:
  - 技术实现(框架/数据库)→ 归 L5 技术架构
  - 流程细节(泳道/单据流转)→ 归 L1 业务架构
  - 字段级数据字典 → 归 L3 数据架构

## 4. 背景

业务约束真源为 **ADR-0011**(贵金属检测业务约束):黄金为核心对象,火试金为仲裁方法,报告具法律效力。schema.prisma 已有 30 个模型,但**未做过显式领域建模**——本层将 30 模型映射到限界上下文,识别聚合边界与事件,确保后续 L1-L4 设计不偏离业务。

## 8. 业务流程

领域级主流程(跨上下文,细化归 L1):

```
[身份域] → [样品域] → [批次域] → [检测域] → [QC域] → [报告域] → [归档]
   委托登记 → 样品接收 → 批次编排 → 火试金/ICP执行 → 质控验证 → 报告签发 → 留样归档
```

支撑流程:设备域(校准/维护)↔ 检测域;试剂域 ↔ 检测域;方法域 ↔ 检测域;EHS 域(横切)。

### 9.2 聚合根与状态

| 聚合根 | 状态机(简) | 关键不变量 |
|---|---|---|
| Sample(样品) | RECEIVED → BATCHED → IN_TEST → TESTED → REPORT_DRAFT → REPORT_REVIEW → REPORT_APPROVED → ARCHIVED / REJECTED | 编号唯一、留样 ≥6 月 |
| SampleBatch(批次) | PENDING → MIXING → FUSING → CUPELLING → PARTING → ANNEALING → WEIGHING → CALCULATING → COMPLETED / REJECTED | 平行样 ≥3 |
| Test(检测) | PENDING → IN_PROGRESS → COMPLETED / QC_FAILED / REJECTED | 结果需 QC 验证 |
| Report(报告) | DRAFT → REVIEW → APPROVED → SIGNED → DELIVERED / REJECTED | 三级审核、电子签名 |
| Equipment(设备) | ACTIVE → MAINTENANCE → RETIRED / BROKEN | 校准有效期 |
| Reagent(试剂) | ACTIVE → EXPIRED / DEPLETED | 效期预警 |

## 12. 业务规则

| 编号 | 规则 | 来源 | 可测试性 |
|---|---|---|---|
| BR-D-01 | 火试金每批平行样 ≥ 3 份 | ADR-0011 | 创建批次时校验 replicateCount ≥ 3 |
| BR-D-02 | 报告签发前 QC 必须通过(qcPassed=true) | CNAS §7.7 | 状态机守卫 |
| BR-D-03 | 样品编号唯一且格式 YYMMDD-NNNN | ADR-0011 | schema unique + 格式校验 |
| BR-D-04 | 火试金 QC 样回收率 99.5-100.5% | ADR-0011 | recordWeights 校验 |
| BR-D-05 | Au≥99.9% 时平行样 RSD ≤ 0.3% | GB/T 9288 | 计算模块校验 |
| BR-D-06 | 留样 ≥ 6 个月(贵金属) | ADR-0011 | 归档策略 |
| BR-D-07 | 检测结果必须关联方法与设备 | CNAS §7.2/§7.5 | 数据完整性校验 |
| BR-D-08 | 报告必须三级审核(起草→审核→批准→签发) | CNAS §7.8 | 状态机强制 |
| BR-D-09 | 标准物质(reference_materials)用于 QC 样 | ADR-0011 | QC 关联校验 |
| BR-D-10 | 设备过期校准不得用于检测 | CNAS §6.4 | 设备状态校验 |
| BR-D-11 | 超出能力范围的检测请求拒绝 | CNAS §6.1 | 合同评审校验 |
| BR-D-12 | 审计日志 append-only 不可改 | ALCOA+ Original | DB trigger |

## 13. 异常处理

| 异常场景 | 检测方式 | 响应策略 |
|---|---|---|
| 领域冲突(平行样不达标) | RSD 计算 | 批次 REJECTED + 调查 |
| 并发修改同一聚合 | 乐观锁(version) | 冲突重试/人工裁决 |
| 样品状态非法流转 | 状态机守卫 | 拒绝 + 审计记录 |
| QC 失败 | qcPassed=false | 复测流程 + 偏差记录 |

## 20. 附录

### 20.1 领域术语表(节选,≥ 50 词见随附词汇表)

| 术语 | 定义 |
|---|---|
| 火试金法 | 高温熔融 + 铅扣灰吹 + 分金称重的黄金纯度仲裁方法 |
| 铅扣 | 试样与铅助熔剂熔融后形成的含贵金属铅合金 |
| 灰吹 | 铅扣在灰吹炉中氧化除铅,留下金银合粒 |
| 分金 | 硝酸溶解银,分离金的过程 |
| 合粒 | 灰吹后剩余的金银合金颗粒 |
| 平行样 | 同一样品的多份独立试料 |
| 标准物质 | 有证书的参考物质(如 GBW02757) |
| 留样 | 检测后按规定期限保存的样品 |
| 检出限(LOD) | 方法可检出的最低浓度 |
| 定量限(LOQ) | 方法可定量测定的最低浓度 |
| 不确定度 | 测量结果与真值偏离的估计(k=2) |
| 加标回收率 | 加标样品测得增量与理论增量之比 |
| 能力验证(PT) | 外部比对验证实验室能力 |
| 期间核查 | 两次校准之间对设备的核查 |
